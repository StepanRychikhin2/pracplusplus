## Дані для перевірки

### Завдання 1

Порядок введення: n, спосіб створення (1 або 2), потім n чисел для способу 1.

| Вхідний масив | Мінімум, індекс | Максимум, індекс | Вихідний масив |
|---|---|---|---|
| 5 -2 9 3 -2 | -2, 1 | 9, 2 | 5 9 -2 3 -2 |
| 4 4 4 | 4, 0 | 4, 0 | 4 4 4 |
| 7 | 7, 0 | 7, 0 | 7 |
| -3 -1 -2 | -3, 0 | -1, 1 | -1 -3 -2 |

Повний приклад введення:

```text
5
1
5 -2 9 3 -2
```

Для генерації десяти елементів введіть `10`, потім `2`.

### Завдання 2

Порядок введення: n, спосіб створення, елементи для способу 1, режим виведення, ключ пошуку.

| Вхідний масив | Ключ | Результат сортування | Порівнянь сортування | Обмінів | Індекс ключа | Порівнянь пошуку |
|---|---:|---|---:|---:|---:|---:|
| 3 1 2 1 | 1 | 1 1 2 3 | 6 | 4 | 0 | 1 |
| 3 1 2 1 | 9 | 1 1 2 3 | 6 | 4 | не знайдено | 4 |
| 1 2 3 4 | 3 | 1 2 3 4 | 3 | 0 | 2 | 3 |
| 4 3 2 1 | 4 | 1 2 3 4 | 6 | 6 | 3 | 4 |
| 7 | 7 | 7 | 0 | 0 | 0 | 1 |
| 2 2 2 | 1 | 2 2 2 | 2 | 0 | не знайдено | 3 |

Повний приклад із показом проходів:

```text
4

```

Для генерації десяти елементів, показу тільки кінцевого масиву та пошуку числа 5 введіть: `10`, `2`, `1`, `5`.

### Завдання 3

Порядок введення: три координати X, спосіб створення a, b, c, потім координати кожного вектора для способу 1.

Повне введення для контрольного тесту:

```text
-4 4 4
1
3 1 0
-1 0 6
-1 2 0
```

| X | a; b; c | Очікуваний результат |
|---|---|---|
| (-4; 4; 4) | (3; 1; 0); (-1; 0; 6); (-1; 2; 0) | X = -8/21*a + 2/3*b + 46/21*c |
| (1.25; -2.5; 0) | (1; 0; 0); (0; 1; 0); (0; 0; 1) | X = 1.25*a - 2.5*b + 0*c |
| (1; 2; 3) | (0.5; 0; 0); (0; 0.25; 0); (0; 0; 1.5) | X = 2*a + 8*b + 2*c |
| (0; 0; 0) | (1; 0; 0); (0; 1; 0); (0; 0; 1) | X = 0*a + 0*b + 0*c |
| (1; 2; 3) | (1; 0; 0); (2; 0; 0); (0; 0; 0) | D = 0, правило Крамера незастосовне |

Для генерації векторів введіть координати X, наприклад `1 2 3`, а потім `2`. Випадково отримані вектори теж можуть бути залежними: цей випадок обробляється так само, як при ручному введенні. Генератор ініціалізується поточним часом у секундах; запуски в межах однієї секунди можуть давати однакові набори.

### Неправильне введення

Перевіряються n = 0, від'ємне n, n > 100, дробове n, неправильні пункти меню, текст замість числа, дробові елементи цілочисельного масиву, переповнення типу та відсутність потрібних чисел. У третьому завданні додатково перевіряються межі координат. Після помилки обчислення пропускаються, а програма доходить до кінця звичайним шляхом.

## Організація програми

У кожному main залишені тільки Consol, Info та Run. Назви функцій короткі, англійською, пояснення й повідомлення — українською. Кожний файл cpp є самостійною програмою.

Основні змінні оголошені глобально. У першій програмі це arr[100], n, choice, imin та imax. У другій — arr[100], n, choice, view, key, countSort, swaps, countSearch і pos. У третій — масиви x, a, b, c по три координати, визначники d, d1, d2, d3 та коефіцієнти k1, k2, k3. Змінна ok показує, чи правильне введення.

Функції Make, Print, MinMax, Swap, BubleSort та Find працюють безпосередньо з глобальними даними. Масиви не передаються через параметри. Немає покажчиків, new, delete, STL-контейнерів, бібліотечного сортування чи пошуку.

Введення перевіряється короткою функцією Chek та звичайними умовами. При помилці повторне введення не організовується: програма виводить повідомлення і завершується звичайним шляхом. Для масивів і пошуку використовуються цикли for. Функція Gcd скорочує дроби циклом do while; її другий аргумент завжди додатний.

У циклах є умови завершення. Немає нескінченних циклів, break, continue, goto, exit та дострокових return. Функції, що повертають значення, мають одне повернення в кінці.

У коді коефіцієнти alpha, beta, gamma позначені k1, k2, k3.

У третьому завданні Det(0) обчислює визначник зі стовпцями a, b, c. Виклики Det(1), Det(2), Det(3) замінюють відповідний стовпець вектором X. Функція спочатку копіює координати у три звичайні локальні масиви aa, bb, cc, тому вхідні вектори не змінюються.

Основні функції:

- Завдання 1: Make, MinMax, Swap, Print.
- Завдання 2: Make, BubleSort, Find, Search.
- Завдання 3: ReadX, ReadNum, MakeVec, Det, Gcd, PrintNum, PrintPart, ChekRes.

Алгоритм сортування та підрахунок операцій не змінені: прохід без обмінів завершує сортування. Пошук зупиняється на першому збігу. Тому наведені контрольні відповіді та формули перевірки в Excel залишаються придатними.

## Файли та запуск

- task1.cpp, task2.cpp, task3.cpp — вихідний код трьох окремих програм.
- task1.exe, task2.exe, task3.exe — готові програми для Windows зі статично підключеною бібліотекою виконання MinGW.
- task1.drawio — основна програма, створення масиву, пошук мінімуму та максимуму.
- task2.drawio — основна програма, створення масиву, бульбашкове сортування, лінійний пошук.
- task3.drawio — розкладання вектора, створення векторів, форматування коефіцієнта та скорочення дробу.

Чорно-білі схеми відкриваються у draw.io (diagrams.net); окремі алгоритми розміщені на вкладках. Блоків налаштування консолі та виведення автора на схемах немає.

Команди компіляції з папки labs/lab6:

```powershell
g++ -pipe -std=c++17 -Wall -Wextra -Wpedantic -c task1.cpp -o task1.o
g++ -static task1.o -o task1.exe
g++ -pipe -std=c++17 -Wall -Wextra -Wpedantic -c task2.cpp -o task2.o
g++ -static task2.o -o task2.exe
g++ -pipe -std=c++17 -Wall -Wextra -Wpedantic -c task3.cpp -o task3.o
g++ -static task3.o -o task3.exe
```

Компіляцію та збирання розділено на два кроки, щоб уникнути проблем MinGW із тимчасовими файлами у шляху з українськими літерами. Файли .o є проміжними й після збирання не потрібні.

Запускайте програми з термінала, щоб після завершення результат залишався на екрані:

```powershell
./task1.exe
./task2.exe
./task3.exe
```

Автоматична перевірка в `output/lab6/verify_lab6.py` виконує 206 запусків готових програм: контрольні та граничні приклади, обидва способи створення даних, обидва режими сортування, лічильники, дроби й помилки введення. Python потрібний лише для цієї перевірки та допоміжного створення схем; самі програми працюють без нього.
