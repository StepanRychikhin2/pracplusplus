## Мета

Навчитися обробляти двовимірні масиви, працювати з головною діагоналлю, обчислювати визначники, мінори, алгебраїчні доповнення та обернену матрицю.

## Завдання 1

Створити квадратну матрицю. Знайти суму елементів на головній діагоналі або над нею, які більші за всі елементи під діагоналлю. Записати суму в додатковий рядок та стовпець. Вивести початкову матрицю, суму та змінену матрицю; перевірити наявність місця для розширення.

Використано глобальний масив `arr[10][10]`. Дозволено n від 3 до 10. При n від 3 до 9 матриця розширюється. При n = 10 програма виводить вхідну матрицю, суму та повідомлення про неможливість додати 11-й рядок і стовпець. Запису за межі масиву немає. Розміри поза межами 3–10 відхиляються до заповнення масиву.

Спосіб 1 — введення цілих чисел від −1000000 до 1000000 по рядках. Спосіб 2 — випадкові числа від −10 до 10.

### Як обчислюється сума

1. Під головною діагоналлю індекс рядка більший за індекс стовпця: `i > j`. Серед цих елементів знаходимо максимум `big`.
2. На діагоналі та над нею виконується `j >= i`. Додаємо елемент до `sum`, якщо `arr[i][j] > big`.
3. Порівняння строге: елементи, рівні максимуму під діагоналлю, не додаються.
4. Якщо місця вистачає, записуємо суму в `arr[n][i]` і `arr[i][n]` для i від 0 до n включно. Новий нижній правий елемент також дорівнює сумі.

Максимум починаємо з `arr[1][0]`, а не з нуля: так правильно обробляється матриця, у якій усі числа від'ємні. Якщо жоден елемент не підходить, сума дорівнює нулю.

### Дані для перевірки

Ввести в консоль повністю:

```text
3
1
5 8 2
1 6 9
3 4 7
```

Перший рядок — n, другий — ручне введення, наступні три — матриця. Під діагоналлю розташовані 1, 3, 4. Максимум — **4**. Потрібна сума: **5 + 8 + 6 + 9 + 7 = 35**.

Очікувана модифікована матриця:

```text
 5  8  2 35
 1  6  9 35
 3  4  7 35
35 35 35 35
```

Ще один повний тест:

```text
3
1
-5 -2 -3
-9 -4 -6
-8 -7 -1
```

Максимум під діагоналлю — **−7**, сума — **−21**. Додатковий рядок і стовпець мають містити −21.

| Перевірка | Очікуваний результат |
|---|---|
| Матриця 3×3, усі елементи 4 | Сума 0; новий рядок і стовпець складаються з нулів |
| Одинична матриця 3×3 | Сума 3 |
| n = 9, спосіб 2 | Виведення вхідної 9×9 та модифікованої 10×10 матриці |
| n = 10, спосіб 2 | Вхідна матриця, сума та повідомлення про вихід за межі при розширенні |
| n = 2 або n = 11 | Повідомлення про помилку введення |

Для випадкового заповнення достатньо ввести `3`, потім `2`.

## Завдання 2

Створити квадратну матрицю та обчислити обернену за формулою:

```text
A^(-1) = C^T / det(A)
C[i][j] = (-1)^(i+j) * M[i][j]
```

Тут C — матриця алгебраїчних доповнень (у програмі `adds`), а M[i][j] — визначник матриці без рядка i та стовпця j. Це та сама формула, що на фото до умови.

Розмір m від 3 до 6, ручне введення цілих чисел від −100 до 100. Таке обмеження зберігає швидку роботу рекурсивного розкладання визначника та виключає переповнення `long long`: навіть оцінка `6! * 100^6 = 720000000000000` значно менша за його максимальне значення. Визначники й доповнення обчислюються цілими числами точно. Елементи оберненої матриці зберігаються як `long double` і виводяться з 10 значущими цифрами.

Спосіб 1 — ручне введення; спосіб 2 — генерація чисел від −10 до −1 та від 1 до 10. Знак кожного випадкового числа обирається окремо; наявність обох знаків у конкретній матриці не гарантується.

Режим 1 виводить вхідну матрицю, визначник та обернену матрицю. Режим 2 додатково показує кожний мінор і кожне алгебраїчне доповнення. Номери рядків та стовпців у повідомленнях починаються з 1.

### Як працює алгоритм

1. Копіюємо `arr` у допоміжну матрицю `temp` та викликаємо `Det(0)` для знаходження визначника.
2. Якщо визначник дорівнює нулю, оберненої матриці не існує. Виводимо повідомлення; ділення не виконується.
3. Для кожної пари i, j функція `Minor(i, j)` копіює у `temp` елементи без відповідного рядка та стовпця.
4. Обчислюємо визначник отриманої матриці. Це мінор M[i][j]. При непарному i + j змінюємо його знак — отримуємо алгебраїчне доповнення.
5. Записуємо `back[j][i] = (long double)adds[i][j] / d`. Переставлені індекси j та i виконують транспонування. Перетворення типу перед діленням зберігає дробову частину.

### Для чого Det та used

`Det(row)` обчислює визначник розкладом за першим рядком, який ще не викреслили. Під час рекурсії номер цього рядка зростає. Масив `used` позначає вже викреслені стовпці. Перед рекурсивним викликом ставимо `used[j] = true`, після повернення відновлюємо `false`. Знак чергується лише між доступними стовпцями.

Коли всі рядки опрацьовані (`row == dim`), функція повертає 1 — це завершує добуток вибраних елементів. Оскільки `used` глобальний, спочатку всі його елементи дорівнюють false. Після кожного повного виклику `Det(0)` вони знову дорівнюють false.

### Дані для перевірки

Повне введення з показом доповнень:

```text
3
1
1 2 3
0 1 4
5 6 0
2
```

Порядок: m, спосіб створення, рядки матриці, режим виведення. Для виведення тільки кінцевих результатів замінити останнє `2` на `1`.

Визначник: **1**. Матриця алгебраїчних доповнень:

```text
-24  20 -5
 18 -15  4
  5  -4  1
```

Обернена матриця:

```text
-24  18  5
 20 -15 -4
 -5   4  1
```

Для перевірки помножити початкову матрицю на обернену: результатом має бути одинична матриця. Наприклад, перший елемент добутку: `1*(-24) + 2*20 + 3*(-5) = 1`, наступний: `1*18 + 2*(-15) + 3*4 = 0`.

Тест з дробовою відповіддю:

```text
3
1
2 0 0
0 -3 0
0 0 4
1
```

Визначник **−24**, обернена матриця:

```text
0.5              0    0
  0  -0.3333333333    0
  0              0 0.25
```

Тест з нульовим визначником:

```text
3
1
1 2 3
2 4 6
0 1 1
2
```

Очікується визначник **0** та повідомлення, що оберненої матриці не існує.

Для випадкової матриці 3×3 з проміжними результатами ввести послідовно `3`, `2`, `2`. Випадкова матриця теж може мати нульовий визначник — це правильний окремий результат, а не помилка генерації.

## Організація програм

Основні змінні та масиви глобальні. Назви функцій короткі: `Make`, `Print`, `FindSum`, `Add`, `Minor`, `Det`, `Invers`, `PrintBack`, `Run`. У `main` залишено виклики `Consol`, `Info`, `Run`.

`Chek` перевіряє, що число зчиталося і відразу після нього немає зайвих символів. Наприклад, `3.5` або `3abc` не приймаються за цілий розмір 3. Межі чисел і правильність пунктів меню перевіряються звичайними умовами. При помилці програма виводить повідомлення та завершується; для нового введення її треба запустити ще раз.

Масиви фіксованого розміру. Немає покажчиків, динамічних масивів, `new`, `delete`, STL-контейнерів, ітераторів або готових матричних алгоритмів. `iostream` та `iomanip` використовуються для введення і виведення; `rand` та `srand` — для псевдовипадкових чисел. Матриці не передаються як параметри функцій.
